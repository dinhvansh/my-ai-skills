## Classification Rules

| Status | Meaning | Recommended Action |
|---|---|---|
| CORE_DOCS | Important active documentation | Rewrite or update |
| DRAFT_DOCS | Temporary prompt, plan, or dev note | Move to `docs/archive/old-prompts` or `docs/archive/old-plans` |
| OUTDATED_DOCS | No longer matches current source code | Move to `docs/archive/outdated` |
| DUPLICATE_DOCS | Duplicates another document | Merge useful content, then archive |
| REFERENCE_DOCS | Useful reference but not core docs | Move to `docs/reference` |
| UNKNOWN_DOCS | Purpose unclear | Move to `docs/archive/unknown` and flag for review |
