# Curated Developer Library

Danh mục GitHub, AI Skills và MCP đã trao đổi. **Không thay đổi các thư mục `skills/`, `templates/` hay `examples/` đang có** trong repository này.

| Thư viện | Nội dung | Số mục |
|---|---|---:|
| [GitHub / Open Source](github/README.md) | Công cụ, dự án open-source, framework và repository đã tìm hiểu | 46 |
| [AI Skills](skills/README.md) | Custom skills, community skills, reference docs | 13 |
| [MCP Servers](mcp/README.md) | MCP connectors/servers đã thảo luận | 2 |

### Quy trình bổ sung

1. Kiểm tra link gốc và đối chiếu URL (không thêm bản trùng).
2. Xác định loại: GitHub/Tool, Skill, hoặc MCP (một dự án có thể được cross-reference giữa các danh mục).
3. Ghi tên, URL, công dụng, trạng thái. Phân biệt **chưa kiểm chứng**, **muốn thử**, **đã thử**, **đang dùng**.
4. Kiểm tra license, quyền/secret và các rủi ro trước khi đề xuất cài.
5. Commit bản cập nhật vào GitHub; **không tự động coi một mục đã lưu nếu chưa có commit thành công**.

> Repo này là Public: không upload code nội bộ chưa được duyệt, mật khẩu, API keys, ZIP có credentials, connection string, log chứa dữ liệu công ty, hoặc source của các skill nội bộ chưa được chấp thuận công khai.
