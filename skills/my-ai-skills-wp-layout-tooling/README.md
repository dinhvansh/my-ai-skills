# My AI Skills - WordPress Layout Tooling Pack

This pack contains reusable skills, prompts, examples, and MCP setup notes for analyzing website/page references and rebuilding original WordPress layouts, especially with Flatsome/UX Builder style workflows.

## Folders

```txt
skills/
  flatsome-reference-rebuild/
tooling/
  browser-analysis/
  mcp-install/
```

## Fast Install Into Your Repo

From your repo root:

```bash
unzip my-ai-skills-wp-layout-tooling.zip
git add skills/flatsome-reference-rebuild tooling/browser-analysis tooling/mcp-install README.md
git commit -m "Add WordPress layout analysis and Flatsome rebuild skills"
git push
```

## Safe Usage

Use references for layout analysis and planning only. Replace all final text, images, logo, icons, brand colors, product data, and assets with your own materials before publishing.
