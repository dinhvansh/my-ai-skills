# flatsome-reference-rebuild

Skill for turning an approved design brief, owned screenshot, or page reference into an original WordPress/Flatsome layout plan.

## What It Produces

- Page type
- Section breakdown
- Flatsome element mapping
- UX Builder shortcode draft
- Custom CSS
- Responsive notes
- Implementation checklist
- QA checklist

## Example Prompt

```md
Use the flatsome-reference-rebuild skill.

Analyze this page reference: <URL or screenshot>
Create an original WordPress/Flatsome homepage layout.

Return:
1. Section breakdown
2. Flatsome UX Builder mapping
3. Shortcode draft
4. Custom CSS
5. Responsive checklist
6. Asset replacement checklist
```
